# Code of conduct

## The short version

Be decent. Assume the other person is trying to help. Critique code, not
people.

## What that rules out

Harassment, personal attacks, demeaning or discriminatory comments, sexual
attention or advances, sustained disruption, publishing anyone's private
information, and following someone from thread to thread to keep at them.

This applies in issues, pull requests, commit messages, code review, and
anywhere else the project is being discussed.

## A specific note for this project

Contributions here can involve people's real shopping receipts. **Redact
before you post.** No names, addresses, card digits, order links, or account
identifiers — in an issue, a recipe example, a test fixture, or a screenshot.
Anyone can ask for a redaction and it will be honoured without argument.

## Reporting

Raise it privately with the maintainer via the **Security** tab's private
reporting, or a direct message on GitHub. Reports are read in confidence.

The maintainer will edit, hide, or delete comments that break this, and may
block accounts that keep doing it. If you think a moderation decision was
wrong, say so — that conversation is welcome.

Adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org),
shortened so that it actually gets read.
